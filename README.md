# Son Dakika Bahane Üreticisi 🚀

## Bu Repo Nedir?

Bu, insanlık tarihinin en önemli yazılım projesidir. Son dakika bahaneleri üretmek için tasarlanmış, gerçekten çalışan, aşırı ciddi bir mühendislik harikasıdır.

Artık "bir dakika" demek zorunda değilsin. Bu kod senin yerine düşünür, bahaneyi üretir ve hayatını kurtarır.

**Uyarı:** Bu kodu çalıştırdıktan sonra sorumluluk kabul etmiyoruz. Çünkü bahane zaten üretilmiş olur.

## Nasıl Çalıştırılır?

```bash
python bahane_ureticisi.py
```

Çalıştır, bekle, bahane al. Bu kadar. NASA bunu görse ağlardı.

## Özellikler

- Gerçekten çalışıyor (test edildi).
- Rastgele Türkçe bahaneler.
- Quantum flüktuasyon simülasyonu (asılında sadece sleep).
- Damga ve imza içerir.
- %1 ihtimalle gizli not sızdırır (merak etme, kimse anlamaz).
